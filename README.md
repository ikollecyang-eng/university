# 🎓 University Management System（learning assignment）

一个基于 Java 的高校信息管理系统，用于实现学生、教师、课程等信息的统一管理。

---

## 📌 项目简介

本项目是一个面向高校场景的综合管理系统，主要用于完成：

- 学生信息管理
- 教师信息管理
- 课程管理
- 成绩管理
- 数据查询与统计

项目旨在模拟真实校园管理业务流程，提升数据库设计、后端开发与系统架构能力。

---
